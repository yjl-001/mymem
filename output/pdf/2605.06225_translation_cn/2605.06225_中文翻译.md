# Memory Inception：用于 Steering LLM 的 Latent-Space KV Cache 操作

Andy Zeyi Liu、Michael Zhang、Ilana Greenberg、Adam Alnasser、Lucas Baker、John Sous

## 摘要

对大语言模型进行 steering 通常有两条路线：instruction prompting 或 activation steering。Prompting 往往控制力强，但会把 guidance tokens 缓存在每一层，并在长交互中污染可见上下文；activation steering 更紧凑，但通常更弱，也不自然支持大型结构化提醒。

本文提出 **Memory Inception (MI)**，一种无需训练的方法：它在 latent attention space 中进行 steering，只在选定层插入由文本派生出的 key-value (KV) banks。MI 不把 reminder content 在 prompt cache 中处处 materialize，而是把 steering 看成 selective KV allocation：只有当模型会路由到某些 latent slots 时，才把这些 slots 注入对应位置。

在 matched personality-steering 任务上，MI 在 control-drift trade-off 上取得最佳整体结果，与 prompting 竞争，同时持续优于 CAA。在可更新 guidance 上，MI 支持对话中途行为切换，而无需重写可见 transcript，并在 Qwen3 上取得最高 post-shift alignment。在结构化推理上，MI 在 HARDMath 与 PHYSICS 中多数条件下优于 visible prompting，并将 content-matched KV storage 最多降低 118 倍。这些结果说明，当 guidance 是持久、结构化、或放在可见 transcript 中成本很高时，MI 是一种有力 steering 方法。

## 1. 引言

语言模型经常需要持久 guidance，而不是一次性指令。例如，用户希望 assistant 在问卷中保持某种人格特质，在多轮对话中维持语气，在回答后续问题时保持某个长上下文事实活跃，或在领域 benchmark 中应用一组推理 heuristics。标准方案是 prompting：把 reminder tokens 插入可见上下文，并在每一层缓存。另一类方法是 activation steering：通过学习或对比得到的 residual directions 直接改变 hidden states。

这两种接口的取舍相反：prompting 暴露 reminder text，并在所有层存储它；activation steering 紧凑，但不天然 text-faithful，也不易更新。

本文研究第三种接口：**latent attention state**。Memory Inception 如图 1 所示，是一种无需训练的方法。它把 descriptor、summary、retrieved fact 或 task heuristic 编码成 latent key-value slots 的 bank，并让选定 attention layers/heads 在普通 prompt tokens 之外也 attend 到这些 slots。Reminder 因而只在 attention 读取它的位置可用，而不是作为可见文本反复 materialize，也不是作为 query-independent residual offset 注入。

图 1. Memory Inception (MI)：简洁 reminder text 被编码成 latent KV memory-bank slots，并只在自动选出的 layers、heads 或 KV groups 中追加。不同于 prompt steering，reminder 在推理时位于可见 transcript 之外，也不必存储在每一层；不同于 CAA-style activation steering，MI 通过对 latent reminder slots 的 query-dependent attention 起作用，而不是全局 residual-vector offset。

Prompt steering 会在所有层存储 guidance-derived KV states，即使真正驱动控制的只有少数层。MI 则把 guidance 看成 selective KV-allocation 问题：先识别 reminder 真正需要出现的 layers 和 attention units，再只在那里插入 latent slots。层级 KV footprint 从全部 $L$ 层缩小为 $L_{ctrl}$ 个 controlled layers。

概念上，prompting 与 activation steering 位于两个设计轴的两端：visible vs. latent control content，以及 global vs. selective intervention。MI 位于中间：它由文本条件化，但对可见 transcript 隐藏；它局部作用于会路由到 memory 的 attention sites。对人格、语气、推理 heuristics 这类隐式信号，问题不再是 reminder 能否被 everywhere cached，而是它究竟需要存在于哪里。

本文评估 MI 的三个 regime：

1. matched personality-steering：prompting、CAA、MI 接收同一 control signal，测试 latent KV steering 是否改善 control-drift trade-off。
2. mid-dialogue behavior shift：测试 guidance 能否在不重写可见 transcript 的情况下保持活跃或更新。
3. HARDMath 与 PHYSICS：测试同一机制能否承载 reusable reasoning-heuristic banks，而不只是短 style descriptors。

本文贡献如下：

- **Steering interface。** 提出 Memory Inception，一种无需训练的方法，只在选定层注入 text-conditioned latent KV banks，而不是把 reminder text materialize 到完整 prompt cache 中。
- **解释与实现。** 将方法表述为 prompt、target、reference、auxiliary memories 上的 bank-level attention routing，并给出 canonical-key RoPE 实现，支持 dense attention、grouped-query attention 与 Qwen3-style MoE。
- **经验定位。** 在 personality-steering 上，MI 与 prompting 竞争，同时在 control-drift trade-off 上持续优于 CAA；在 reasoning domains 中，MI 可作为 fine-tuning 的 training-free 替代，在 PHYSICS 平均分上提升，并在 HARDMath 上持续优于 plain model。
- **系统价值。** 当 guidance 持久或结构化时，memory banks 最有用，可将 KV storage 降低 6-118 倍。

## 2. 相关工作

**Prompting 与 latent prompts。** Prompting 仍然是 inference-time steering 的默认接口，从 in-context instructions 到 chain-of-thought scaffolds 都属于此类。相关方法还有 continuous prefixes 或 soft prompts，它们在不改变 base weights 的情况下被注入模型。MI 的目标同样是 inference-time control，但不同之处有二：一是 training-free；二是 steering state 直接由用户提供文本或 task heuristics 在推理时构造，而不是由优化出的 prompt parameters 得到。

**Activation、attention 与 cache steering。** Activation Addition 和 CAA 通过从 prompt pairs 或 positive/negative examples 中得到 residual directions 来 steering 模型。Representation engineering 与 function vectors 也说明，可复用 latent directions 能捕捉高层行为或 in-context functions。更近的 attention-level 方法如 AutoPASTA、Spotlight，通过把 attention 重新分配到 instruction tokens 来 steering；KV Cache Steering 则操作 cached prompt representations 以诱导推理行为。MI 与这些工作的区别在于，它在选定位置追加新的 text-derived KV content，使模型能 attend 到可复用 guidance blocks，而不是把它们压成单个 residual direction 或对 visible prompt tokens 的 bias。

## 3. Memory Inception：形式化与实现

### Overview

Memory Inception (MI) 是一个 training-free steering interface：它把 reminder content 编码成 latent KV banks，并只把这些 banks 接到少量选定 layers 和 attention sites 上，使模型能与普通 prompt tokens 一起 attend 到这些 banks。下面依次形式化 intervention、bank construction 与 KV-cache budget。

### 3.1 Latent Attention Space 中的 Memory Inception

先定义 intervention interface：一个 selected attention site 看见什么，additional banks 接在哪里，以及多个 memory banks 存在时 routing 如何改变。

**Attention。** 考虑 decoder-only Transformer 中的一个 attention site。在 generation step $t$，令 live query 为：

$$
q_t\in \mathbb{R}^{d_h},
$$

其中 $d_h$ 是 head dimension。prompt/history keys 与 values 为：

$$
K_{\le t}^{x}=[k_1^x,\dots,k_t^x]^\top,\quad
V_{\le t}^{x}=[v_1^x,\dots,v_t^x]^\top.
$$

标准 attention output 为：

$$
\mathrm{Attn}(q_t,K_{\le t}^{x},V_{\le t}^{x})
=
\mathrm{softmax}
\left(
\frac{q_t(K_{\le t}^{x})^\top}{\sqrt{d_h}}
\right)
V_{\le t}^{x}.
$$

MI 保持这种 query-dependent attention computation，但在 selected sites 上把候选上下文扩展到可见 prompt/history tokens 之外。

**KV Cache Memory Bank。** 一个 memory bank 是一小组 latent KV slots。Bank $b$ 包含 $M_b$ 个 slots：

$$
B^{(b)}=\{(k_m^{(b)},v_m^{(b)})\}_{m=1}^{M_b},
$$

$$
K^{(b)}=[k_1^{(b)},\dots,k_{M_b}^{(b)}]^\top,\quad
V^{(b)}=[v_1^{(b)},\dots,v_{M_b}^{(b)}]^\top.
$$

在 selected site，MI 概念上把这些 slots 追加到 prompt cache：

$$
K_t^\star=\mathrm{concat}(K_{\le t}^{x},K^{(1)},\dots,K^{(B)}),
$$

$$
V_t^\star=\mathrm{concat}(V_{\le t}^{x},V^{(1)},\dots,V^{(B)}).
$$

得到 selected-site output：

$$
o_t^\star=\mathrm{Attn}(q_t,K_t^\star,V_t^\star).
$$

这是全文使用的 reference formulation。实现中，普通 prompt cache 保持不变，reminder bank 作为 side bank，只在选定 layers 与 units 被消费。选择性是核心设计：reminder slots 只暴露在 controller 预测它们有用的层上。

**Automated Layer and Head Selection。** 选择性由 calibration-time selector 自动处理。给定候选 layers $\mathcal{L}_{cand}$ 与每层候选 attention units $\mathcal{U}_{\ell}$，selector 先根据 query 与 target bank 相对 reference bank 的 alignment 强度打分：

$$
a_{\ell,u}
=
\max_j\frac{q_{\ell,u}^{\top}k_{\ell,u,j}^{+}}{\sqrt{d_h}}
-
\max_j\frac{q_{\ell,u}^{\top}k_{\ell,u,j}^{-}}{\sqrt{d_h}}.
$$

然后每层保留 top-$k$ units，聚合这些分数对 layers 排序，并保留 top-$m$ layers。输出是 frozen selector artifact，指定 selected layers、selected units 与 layer-wise gains $\rho_{\ell}$。

直观上，MI 先决定 reminder access 应该在哪里可用，然后只修改这些 sites，使它们的 queries 能更强地路由到 memory bank。可选 unit 取决于架构：Meta-Llama-3.1-8B-Instruct 中是 attention head；Qwen3-30B-A3B 中是 grouped-query KV group，并在 patch 时展开到对应 query heads。

**Bank-level mixture。** 当只有一个 reminder bank 时，selected site 只需在 prompt/history tokens 与该 bank 之间选择。当存在多个 banks 时，bank-level mixture 视角更有用。令 $b=0$ 表示 prompt bank，$b=1,\dots,B$ 表示 memory banks。定义 slot scores：

$$
s_{t,m}^{(b)}=\frac{\langle q_t,k_m^{(b)}\rangle}{\sqrt{d_h}},
$$

$$
\alpha_{t,m}^{(b)}
=
\frac{\exp(s_{t,m}^{(b)})}
{\sum_r \exp(s_{t,r}^{(b)})},
$$

$$
o_t^{(b)}
=
\sum_m \alpha_{t,m}^{(b)}v_m^{(b)}.
$$

令：

$$
\tilde{\beta}_t^{(b)}
=
\log
\left(
\sum_{m=1}^{M_b}\exp(s_{t,m}^{(b)})
\right)
c_t^{(b)}
$$

表示 bank $b$ 的 evidence，其中 $c_t^{(b)}$ 收集 bank-level gain 或 prior term。则 selected-site output 可写为：

$$
o_t^\star
=
\sum_{b=0}^{B}\tilde{\pi}_t^{(b)}o_t^{(b)},
\quad
\tilde{\pi}_t
=
\mathrm{softmax}
([\tilde{\beta}_t^{(0)},\dots,\tilde{\beta}_t^{(B)}]).
$$

为防止更大的 bank 仅凭 slot 数量赢得 routing weight，作者使用 size-normalized evidence：

$$
\beta_t^{(b)}
=
\tilde{\beta}_t^{(b)}-\log M_b
=
\log
\left(
\frac{1}{M_b}\sum_{m=1}^{M_b}\exp(s_{t,m}^{(b)})
\right)
c_t^{(b)}.
$$

因此，prompt、target、reference、auxiliary banks 通过 query-dependent bank evidence 竞争，而不是通过全局 residual offset 竞争。

### 3.2 构造 Memory Banks

上一节把 memory banks 看成抽象 latent objects；本节说明 reminder text 如何转换为可复用 KV slots。

**Text-Derived Memory Banks。** Banks 可以由 persona descriptors、dialogue summaries、retrieved facts、safety notes 或 task heuristics 构建。所有 text-derived banks 使用共享 recipe：

1. 将 source text 放入一个或多个 templates，例如 direct descriptor、internal-principles wrapper、hidden-steering-note wrapper。
2. 用 frozen base model 运行 wrapped text，记录每个 token position 的 hidden states。
3. 只保留与 descriptor content 对齐的位置，除非实验明确保留完整 wrapped text。
4. 对每个 selected layer $\ell$ 和 selected key-value unit $u$，将保留 hidden states 归一化，并通过模型自身 key/value projections：

$$
k_{\ell,u,m}^{(b)}
=
W_{K,u}^{(\ell)}\mathrm{Norm}_{\ell}(h_{\ell,m}^{(b)}),
$$

$$
v_{\ell,u,m}^{(b)}
=
W_{V,u}^{(\ell)}\mathrm{Norm}_{\ell}(h_{\ell,m}^{(b)}).
$$

当前实现中，每个 bank 会连接原始 descriptor 的 token-level slots，以及同一 descriptor 的 contextualized variants 产生的 slots。

**Canonical Pre-RoPE Key Storage。** Llama-style 与 Qwen3-style decoders 使用 RoPE。令 $R_t$ 是 query position $t$ 的 rotary operator，则：

$$
q_t=R_t\bar{q}_t,
$$

prompt keys 形式为：

$$
k_j^x=R_j\bar{k}_j^x.
$$

如果 memory key 用任意 absolute rotation 存储，它会绑定到 bank 构造时的位置。MI 通过把 memory keys 存储在 canonical pre-RoPE coordinates 中避免这一点。对 canonical key $\tilde{k}_m$ 与可选 relative phase $\delta_m$，memory score 为：

$$
s_{t,m}^{mem}
=
\frac{\langle R_t^{-1}q_t,R_{\delta_m}\tilde{k}_m\rangle}{\sqrt{d_h}}
=
\frac{\langle \bar{q}_t,R_{\delta_m}\tilde{k}_m\rangle}{\sqrt{d_h}}.
$$

默认 $\delta_m=0$，使 bank 与 absolute position 无关。对 grouped-query attention，banks 按 KV head 存储，并展开到共享该 KV group 的 query heads。

**Target、Reference 与 Auxiliary Banks。** 很多 steering 任务受益于多个不同角色的 banks。作者使用 target banks 表示期望行为，optional reference banks 表示相反或不期望行为，auxiliary banks 表示额外 facts 或 heuristics。

在 contrastive setting 中，先测量 target-reference evidence gap：

$$
\Delta_t
=
\log\left(\frac{1}{M^+}\sum_m e^{s_{t,m}^{+}}\right)
-
\log\left(\frac{1}{M^-}\sum_n e^{s_{t,n}^{-}}\right).
$$

再用 query-adaptive gates：

$$
g_t^{\pm}=\sigma(\pm\gamma\Delta_t)
$$

定义 bank-level evidence：

$$
\beta_t^x
=
\log
\left(
\frac{1}{T_t}\sum_j e^{s_{t,j}^{x}}
\right),
$$

$$
\beta_t^+
=
\log
\left(
\frac{1}{M^+}\sum_m e^{s_{t,m}^{+}}
\right)
\rho_{\ell}\lambda^+g_t^+,
$$

$$
\beta_t^-
=
\log
\left(
\frac{1}{M^-}\sum_n e^{s_{t,n}^{-}}
\right)
-
\rho_{\ell}\lambda^-g_t^-.
$$

其中 $\rho_{\ell}$ 是 selector 产生的 layer-wise gain，$\lambda^+$ 与 $\lambda^-$ 是 positive/negative bank gains。Auxiliary banks 使用同样的 bank-evidence interface 和自己的非负 gains。Bank-specific bias 进入 evidence terms，因此主公式不需要额外 free-form logit-bias term。

### 3.3 KV Cache

给定 bank construction 与 placement 后，MI 与 visible prompting 的主要系统差异是：guidance-derived state 需要跨多少层保留。

对于 visible prompt guidance，若有 $T_{prompt}$ 个 tokens、decoder 有 $L$ 层，则 guidance 贡献的 KV-cache storage 与 $LT_{prompt}$ 成正比。一个 memory bank 若有 $S_{bank}$ 个 slots，并只插入 $L_{ctrl}$ 个 controlled layers，则 storage 与 $L_{ctrl}S_{bank}$ 成正比。理想 storage ratio 为：

$$
\mathrm{KV\ ratio}
=
\frac{LT_{prompt}}{L_{ctrl}S_{bank}}.
$$

对 Qwen3-30B-A3B，$L=48$ 且 $L_{ctrl}=5$ 时，若 visible tokens 与 latent slots 数相同，则 ratio 为 $48/5=9.6$。如果 target、reference、template variants 或 auxiliary banks 使 latent slots 多于 prompt baseline 使用的 visible tokens，就应使用实际 slot count 报告。

这解释了为什么 MI 在 guidance 持久或结构化时最有用：reminder 不再需要在每一层占据完整 prompt cache，但仍对会使用它的 selected sites 可用。

## 4. 实验设计

### Models and Baselines

实验评估 Meta-Llama-3.1-8B-Instruct 与 Qwen3-30B-A3B。比较方法包括 plain model、将同一 guidance 放入可见上下文的 prompt baseline、CAA-style activation steering，以及 MI。唯一模型特定差异是 selector 选择 dense attention heads 还是 grouped-query KV groups。对 Qwen3，selector artifacts 可能指定 layer-specific KV groups，而不是单个全局 head set。

高吞吐 Qwen3 评估使用 vLLM 做 batch deterministic generation。Plain 和 prompt baselines 走标准 vLLM 路径；intervention runs 加载 method-specific artifacts。MI 在实现上是 selected-layer side-bank attention path，而不是直接 mutation native paged KV cache。

### Tasks and Metrics

主评估包含四个设置：

- **Big Five self-evaluation。** 使用 IPIP-50-style items，steered model 对每个 item 以单个 Likert digit 作答。报告相对 plain model 的 target shift $\Delta_{target}$ 与 mean absolute non-target drift $D_{non-target}$，并用 drift-adjusted score：

$$
DAS=\Delta_{target}-D_{non-target}.
$$

- **Big Five generation。** 在 open-ended text 中 steering 同一 traits；GPT-4o-mini 判断 target/non-target trait presence 与 coherence。主指标是：

$$
GAS=\Delta_{target}-D_{non-target}.
$$

- **Dialogue shift。** 测试 controller 能否在固定 visible-context budget 下中途更新行为。benchmark 包含 204 个 branching cases，覆盖 support、operational、skill-building、planning 等场景。报告 post-shift alignment $s_{target}-s_{old}$ 与 judged quality。

- **HARDMath 与 PHYSICS。** 作为可验证领域中的结构化推理代理任务。Task heuristics 作为 memory banks 附加；报告 benchmark score。

### Memory-bank construction by task

每个 benchmark family 在 held-out evaluation 前使用特定 bank-construction recipe。Big Five 使用 target-trait descriptor 和 optional opposite-trait reference；问卷 items 和 generation prompts 不进入 bank。Dialogue 任务中，bank 编码 target style 与 optional old-style reference；future turns 不可见。PHYSICS 与 HARDMath 中，作者让 GPT-5.5-thinking 从每个 subject/category 的 5 个 construction examples 中提炼 reasoning heuristics，然后移除 problem text、answers、equations、numerical constants，只保留 natural-language process guidance。construction examples 从 evaluation set 中排除，因此 bank 是 process prior，而不是 test answers retrieval。

### Competitive Steering and Updateable Guidance

Personality steering 是最直接比较：三种方法接收同一 control signal，只是注入位置不同。MI 与 prompting 竞争，并持续优于 CAA：在 Llama self-evaluation 上取得最强 DAS；在 Qwen3 上 DAS 超过 CAA 两倍以上（0.270 vs. 0.115）；generation 上也在两个 backbone 上优于 CAA，同时接近 prompting。MI 在 raw target movement 可能诱发较大 collateral drift 时最有利。

当 visible prompt budget 在 initialization 后固定时，优势更明显：Qwen3 dialogue shift 中，post-shift alignment 从 prompt-init 的 0.438 与 CAA 的 0.526 提升到 MI 的 0.816；24 turns 时从 0.344 提升到 0.651。Llama 上，CAA 在 raw alignment 上领先，但 MI 接近（overall 1.516 vs. 1.554；24 turns 1.344 vs. 1.380），显示 Llama 中 controllability-quality trade-off 更紧。

### Structured Reasoning from Block Guidance

结构化推理是 MI 接口最重要的场景。Subject heuristic、global planner、completion checklist 共同形成可复用 guidance block，适合以 visible text 或 latent bank 注入，但不适合压成单一 residual direction。因此 Table 1 的 reasoning rows 比较 Plain、Prompt、MI。

在 PHYSICS 上，MI 是最明确的正例：12 个 subject-by-mode cells 中赢下 10 个，overall average 最高（76.9%，prompting 75.4%，plain 73.9%）。HARDMath 更混合：visible prompting overall 最高（67.3%），但 MI 仍优于 plain（63.8% vs. 60.8%），并在 8 个类别中的 7 个中赢过或追平 plain。整体说明，MI 能承载可复用 reasoning guidance blocks；但当 benchmark 特别依赖 exact heuristic wording 时，visible prompting 仍可能更有利。

### KV-Cache Savings

图 2 展示了 MI 超越 steering quality 的系统价值。MI 在 long-context Llama case 中将 KV footprint 降低 6.4 倍，在 PHYSICS 上降低 60-118 倍，在 HARDMath 上降低 63-74 倍。guidance 越长，收益越大：短 persona descriptors 主要受益于 selected-layer placement，长 heuristic banks 同时受益于 selected-layer placement 与 prompt-to-slot compression。

## 6. 分析与消融

### Setup and Scope

本节在 Qwen3-30B-A3B 上给出两个消融。第一是 layer-selection ablation：固定 bank content，改变 selected layers 数量，观察不同难度 trait 需要多少 latent coverage。第二是 long-context persistence：在可见交互前追加长 opposite-style prefill，测试 steering signal 能否在竞争上下文中存活。

图 3. Qwen3 layer-selection ablation。Panel A/B 分别报告容易 trait（agreeableness）和困难 trait（neuroticism）随 selected layers 数量增加时的 GAS。Panel C 展示相对于 prompting 的 budget-equivalent KV footprint。

### Layer Ablation

Agreeableness 与 Qwen3 instruction-tuned 默认倾向一致，只需要小幅推动；neuroticism 与默认倾向相反，明显更难。因此，对 agreeableness，一个 layer 已经能提高 trait，10 层附近稳定；对 neuroticism，少于 10 层时分数仍为负，必须把 bank 接到更宽的一段 network 才能有效控制。

资源面板显示，即使最宽的 selected-layer 设置，budget-equivalent KV footprint 仍低于 prompt baseline。困难 traits 需要更广 coverage，但不需要 prompt-style per-layer residency。

### Long-Context Persistence

图 4 在可见交互前加入长 opposite-style prefill。所有方法都会随 prefill 增长而退化，但 MI 退化最少。在 dismissive 与 anxious 这类困难 traits 上，差距更明显：prompt performance 大幅下降，而 MI 在整个范围中保持更强 target behavior。

这一模式来自 MI 设计：visible prompting 必须与新处理上下文的 salience 竞争，而 latent banks 位于 selected attention sites，不受较早 competing context 的同等影响。CAA 比 prompting 更稳定，但 MI 在 hard-trait slice 上最强。

### General Capability Check

作者还在 GSM8K 与 MMLU 上检查 steering 后的一般能力。附录结果显示，MI 相对 plain model 没有明显 capability degradation，并且在出现 drops 的 trait-benchmark pairs 上，退化小于 visible prompting。

## 7. 结论

本文提出 Memory Inception (MI)，一种无需训练的方法，通过向选定 attention layers 追加 text-derived KV banks 来 steering LLM，位于 visible prompting 与 activation steering 之间。MI 在 control-drift trade-off 上优于 CAA，同时与 prompting 竞争；在 Qwen3 上支持不重写可见 transcript 的对话中途行为更新；在 PHYSICS 与 HARDMath 上承载可复用 heuristic blocks。所有设置中，MI 相对 visible prompting 将 content-matched KV storage 降低 6-118 倍，特别适用于 guidance 持久、结构化、或在上下文中保存成本高的场景。

### Limitations

当前结果有三类限制。第一，每个 task family 使用不同 judge 与 scoring protocol：人格任务用 LLM-scored Likert shifts，推理任务用 rubric-based partial credit，跨任务比较间接，不能给出统一 aggregate score。第二，bank quality 依赖任务：slots 若 noisy、过度具体或过宽，可能在新设置中失败；selector 需要 task-specific calibration examples，因此 MI 不是零设计接口。第三，结果部分依赖 backbone：Qwen3 显示最明确的 persistent-guidance gains，而 Llama 有更尖锐 controllability-quality trade-off；cache analysis 测量的是 KV-storage footprint，而不是实际 latency 或 allocator-level VRAM。

最后，latent-steering 机制可用于 persistent hidden guidance，也可能被滥用于 covert behavior shaping 或 hidden policy injection。因此，作者认为真实部署中需要披露 steering artifacts，并提供 auditability。

### Responsible release

由于 latent steering 可以隐藏持久行为 guidance，作者只发布匿名研究代码、评估脚本和 benchmark assets，不发布 deployment-ready steering service 或 covert persuasion / hidden-policy artifacts 的 curated bank。真实部署中，latent steering 应对 operators 披露，steering-bank artifacts 应被访问控制和审计记录，敏感 banks 使用前需人工审核。

## A. 额外相关工作

除主文直接比较的 prompting 与 activation-steering baselines 外，MI 也接近更广义的 inference-time memory mechanisms。RAG、kNN-LMs、Memorizing Transformers、RETRO 在推理时用非参数 external memory 增强模型，主要目标是 factual recall 或 language-model quality；MI 则使用紧凑 text-derived banks 承载行为或推理 heuristics。

另一类相邻工作研究比单一 residual-vector addition 更选择性的 latent steering。Activation Scaling、Improved Representation Steering、conditional activation steering 改进 steering directions 的归一化、组合与条件激活。它们说明无需 retraining 也能控制模型，但仍通过 residual-space interventions 工作，而不是通过 reusable latent KV content。

近期 attention-path 方法更接近 MI。Spotlight 动态提高模型对指定 instructions 的 attention；SEKA 和 Prism-Delta steering key representations 或 attention subspaces 来突出 visible prompt spans；KV Cache Steering 直接干预 cache 以控制 frozen models。MI 的接口不同：它不只 reweight visible prompt tokens，而是把 multi-sentence target、reference 或 heuristic guidance 存为 latent side-bank slots，并可独立于 visible transcript 更新。

### B.1 vLLM 推理实现

Qwen3 实验使用 vLLM 做高吞吐 batch inference。Plain 与 prompt baselines 不需要修改模型。Post-attention CAA 也较简单：它在 projected attention output 之后、该 output 回到 residual stream 之前添加 layer-specific vector。

Memory-bank steering 需要更深的 attention-path integration。虽然公式把 reference method 描述为向可用 keys 与 values 追加 latent slots，但 Qwen3 vLLM 实现不应理解为直接修改 vLLM native paged KV cache。vLLM 继续管理普通 prompt 和 generated-token cache；reminder bank 表示为 side KV bank，只在 selected layers 和 heads/KV groups 中消费。

在 selected Qwen3 layer 中，intervention branch 获取 live query states，应用与 base model 相同的 QK normalization 和 rotary-position treatment，并使用 pre-RoPE normalized query representation 进行 reminder-bank scoring。当前 vLLM path 把已经计算出的 selected-head attention output 当作 prompt-bank output，并为 bank-level routing 使用 synthetic single-slot prompt-bank score。这是对公式中 bank mixture 的近似：target/reference bank outputs 从预计算 side-bank keys/values 得到，但 prompt side 不从完整 native paged prompt KV cache 重建。mixed selected-site output 在 attention output projection 之前写回。对 Qwen3 grouped-query attention，selector artifact 存储 KV groups，patch 会展开到共享该 group 的 query heads。

## C. 自动 Attention Head/Layer Selection

Selector 在 held-out evaluation 前用小 calibration split 自动拟合。Dense Llama-style questionnaire runs 中，calibration pass 记录 attention-route diagnostics，而不是在每个 site 直接优化 task score。统计包括 target/reference alignment margins、prompt-bank mass、target-bank mass、reference-bank mass、phrase-level bank engagement。

**Stage 1: unit ranking。** 令 $\mathcal{L}_{cand}$ 是候选 layers，$\mathcal{U}_{\ell}$ 是第 $\ell$ 层 selectable units。每个 candidate site 分数为：

$$
U_{\ell,u}
=
a_{\ell,u}
\xi m_{\ell,u}^{+}
-
\chi m_{\ell,u}^{x},
$$

其中 $a_{\ell,u}$ 是 target-versus-reference alignment margin，$m_{\ell,u}^{+}$ 是 mean target-bank mass，$m_{\ell,u}^{x}$ 是 mean prompt-bank mass。Dense questionnaire calibration 中，primary ordering 由 $a_{\ell,u}$ 决定，target-bank mass 用作 tie-break 和 engagement diagnostic。每层保留 top-$k$ units。

**Stage 2: layer ranking。** Layer scores 聚合 selected unit scores：

$$
U_{\ell}
=
\mathrm{AggTopK}_{u\in \mathcal{U}_{\ell}}(U_{\ell,u};k).
$$

其中 $\mathrm{AggTopK}$ 是对该层 top-$k$ unit scores 求和或平均。保留 $U_{\ell}$ 最高的 top-$m$ layers。

Selector 输出一个 reusable artifact，包含 selected layers、selected heads 或 KV groups、layer gain schedule $\rho_{\ell}$、bank-mass diagnostics、target/reference alignment margins 与 calibration config。推理时不再搜索：模型加载 artifact，为 requested reminder 构造 banks，并只在 artifact 指定位置应用 attention steering。所有测试结果都在 held-out data 上使用 frozen selector 产生。

## D. 数据集与评估

所有任务中，banks 在 held-out evaluation 前冻结。当 benchmark 需要 construction examples 来诱导 process cards 时，这些 examples 会从 scored pool 中排除。

### D.1 Big Five self-evaluation

Questionnaire benchmark 使用 IPIP-50 Big Five items。作者将模型 steering 到目标 trait，然后逐条展示 questionnaire item，并要求模型给出单个 1-5 Likert response。Reverse-keyed items 在 trait aggregation 前重评分。目标指标是 steered trait 相对 plain model 的变化，non-target drift 是其他四个 traits 的 mean absolute change。

### D.2 Big Five generation

Generation benchmark 使用相同 target traits，但在 free-form responses 上测量。GPT-4o-mini 作为外部 judge，评分 target-trait presence、opposite-trait pressure、五个 Big Five traits 与 coherence。由这些判断计算 target-trait movement、non-target drift 与 contrastive margins。

### D.3 Dialogue shift

Dialogue benchmark 是 multi-turn user trajectories，不是独立 single-turn prompts。语料包含 34 个 scenario roots，每个 root 在 8、16、24 turns 下有两个 branches，总计 $34\times 3\times 2=204$ cases。场景覆盖 emotionally loaded support、operational/crisis、skill-building/habit、planning/creative 等。

Dialogue-shift benchmark 测试 ongoing conversation 中 steering 能否中途改变。每个 scenario root 被分配一个 trait transition：warm->assertive、assertive->warm、formal->cautious、cautious->formal、dismissive->anxious、anxious->dismissive。shift request 在 8/16/24-turn cases 的第 5/9/13 turn 注入。

评分只评估 post-shift assistant turns，由 GPT-4o-mini 给分。令 $s_{target}$ 为新请求 trait 分数，$s_{old}$ 为旧 trait 分数。主 adaptation 指标是：

$$
\mathrm{Align}=s_{target}-s_{old}.
$$

同时报告 post-shift turn-quality score $Q_{turn}$，由 usefulness、specificity、current-turn relevance、non-genericness 平均得到。主比较在 initialization 后保持 visible prompt 与 KV budget 固定；prompt replacement 只作为更高 cache 的 audit condition。

### D.4 HARDMath

HARDMath 是 applied-mathematics stress test。当前评估按 category partial credit 计分，包括 integral、Laplace-integral、ODE、polynomial-roots、nondimensionalization 等 family。原自动 scorer 对数学等价表达过于脆弱，例如将 $1/20$ 与 $0.05$ 视为不同。作者改用 GPT-5.5-thinking 加人工复核，每个答案得 0、0.5 或 1 分。Full credit 要求 boxed answer 在数学等价意义上正确；partial credit 给到部分完整但捕捉到官方答案某个组件的答案。

HARDMath banks 是从 held-out construction examples 中提炼出的 process-only heuristic cards。Plain 只接收 benchmark problem；Prompt 把同一 heuristic guidance 放进可见上下文；Ours 把同一 guidance 存成 latent memory-bank slots。

### D.5 PHYSICS

PHYSICS benchmark 测试 memory banks 能否承载 reusable problem-solving heuristics，而不是 persona reminders。作者使用 text-only PHYSICS split，覆盖 classical mechanics、quantum mechanics、thermodynamics/statistical mechanics、electromagnetism、atomic physics、optics 等 subject。Subject-specific heuristic cards 从 held-out construction questions 提炼，并在 evaluation 前去除 source question text、answer fragments、numerical constants 与 solution-order traces。

答案由 question-specific rubric 评分，GPT-5.5-thinking 每个答案运行三次并报告平均 normalized score。Rubric 基于 partial credit：5 分正确，4 分基本正确但有小问题，3 分 substantial partial credit，2 分有正确 setup 但错误或不完整，1 分进展很弱，0 分错误或不可用。评估包含 no-CoT 与 CoT 设置；CoT 中启用 Qwen3 thinking mode。

### D.6 Long-context persistence

Long-context persistence 使用与 shift benchmark 相同的 204 个 dialogue cases，但 stressor 是长 opposite-style prefill，而不是显式 behavior change request。任务对话开始前，可见上下文被填入 opposing trait 的 non-task assistant-history text。Controller 初始化一次，之后必须在不反复插入可见 instructions 的情况下保持 target style。

GPT-4o-mini 对每个 assistant turn 的六个 style dimensions 和四个 turn-quality dimensions 打分，也对完整 conversation 的 target-style persistence、coherence、user-state consistency、non-repetitiveness、overall quality 打分。

### D.7 GSM8K and MMLU

GSM8K 与 MMLU 只作为 steering 后的粗粒度 capability checks。Qwen3 runs 使用 200 个 GSM8K questions 和 500 个 MMLU questions。这些 benchmark 不用于 tune steering artifacts，只用于确认 persona steering 不会造成明显 capability collapse。

## G. 技术推导

### G.1 Bank-mixture derivation

令 $I_b$ 表示 bank $b$ 的 slots。带 bank-specific slot bias 的 concatenated attention 为：

$$
\tilde{\alpha}_{t,m}^{(b)}
=
\frac{
\exp(s_{t,m}^{(b)}+c_t^{(b)})
}{
\sum_{b'}\sum_{r\in I_{b'}}
\exp(s_{t,r}^{(b')}+c_t^{(b')})
}.
$$

将 numerator 分解为 within-bank softmax 与 bank evidence：

$$
\alpha_{t,m}^{(b)}
=
\frac{
\exp(s_{t,m}^{(b)})
}{
\sum_{r\in I_b}\exp(s_{t,r}^{(b)})
},
$$

$$
\tilde{\beta}_t^{(b)}
=
\log
\sum_{r\in I_b}\exp(s_{t,r}^{(b)})
c_t^{(b)}.
$$

则：

$$
\tilde{\alpha}_{t,m}^{(b)}
=
\tilde{\pi}_t^{(b)}\alpha_{t,m}^{(b)},
$$

其中：

$$
\tilde{\pi}_t^{(b)}
=
\frac{\exp(\tilde{\beta}_t^{(b)})}
{\sum_{b'}\exp(\tilde{\beta}_t^{(b')})}.
$$

因此：

$$
o_t^\star
=
\sum_b\sum_{m\in I_b}
\tilde{\alpha}_{t,m}^{(b)}v_m^{(b)}
=
\sum_b
\tilde{\pi}_t^{(b)}
\sum_{m\in I_b}\alpha_{t,m}^{(b)}v_m^{(b)}
=
\sum_b \tilde{\pi}_t^{(b)}o_t^{(b)}.
$$

从每个 bank evidence 中减去 $\log M_b$，得到正文 Eq. (5) 的 size-normalized 版本。

### G.2 RoPE derivation

有 RoPE 时，query position $t$ 与 key position $j$ 的 prompt score 为：

$$
\frac{\langle R_t\bar{q}_t,R_j\bar{k}_j\rangle}{\sqrt{d_h}}
=
\frac{\langle \bar{q}_t,R_{j-t}\bar{k}_j\rangle}{\sqrt{d_h}}.
$$

对 canonical key $\tilde{k}_m$，分配 virtual relative phase $\delta_m$ 得：

$$
\frac{\langle R_t^{-1}q_t,R_{\delta_m}\tilde{k}_m\rangle}{\sqrt{d_h}}
=
\frac{\langle \bar{q}_t,R_{\delta_m}\tilde{k}_m\rangle}{\sqrt{d_h}}.
$$

因此，memory score 依赖选择的 relative phase，而不依赖 bank 被构建时的 absolute position。默认 $\delta_m=0$ 给出 position-agnostic reminder slot。
